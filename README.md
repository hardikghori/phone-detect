# Live Object Detector

Open the link on any phone or tablet browser, tap Start, allow the camera.
Detects books and phones in real time with YOLO11s (COCO, fp16 ONNX, 480px) on onnxruntime-web, WebGPU with WASM fallback, fully on device.
Add ?fast to the link for YOLO11n (5 MB, faster, less accurate).

Add objects: edit TARGETS in index.html with any of the 80 COCO class names.
